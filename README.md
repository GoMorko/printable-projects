## Gomorko 3D printed projects

This repo contains a copy of various 3d models made and published on [printables.com](https://www.printables.com/@Pozwerty_2313093), [makerworld.com](https://makerworld.com/pl/@go_morko) and so on.

Not everything might be reuploaded here.

Another goal is to provide a source for parametrizable projects
that can be opened and customized in https://paramability.app
